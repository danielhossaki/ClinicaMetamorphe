# Clínica Metamorphe

Site institucional estático em HTML, CSS e JavaScript.

> Projeto desenvolvido para fins de portfólio, como demonstração de um site institucional completo (landing page, páginas internas, SEO, acessibilidade e boas práticas de front-end).

## Estrutura

- `index.html`: página inicial e ponto de entrada.
- `pages/`: páginas de atendimento, legais e blog.
- `assets/`: recursos estáticos, organizados por `css`, `js`, `fonts` e `img`.

## Verificação

```powershell
npm run lint
```
